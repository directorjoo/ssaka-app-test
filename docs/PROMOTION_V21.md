# SSAKA v21 — 쿠폰 공유 및 현장 사용 처리

## 추가 기능
- `/coupon/?shop_key=<매장키>` 고객용 쿠폰 공유 페이지
- 고객은 현재 유효한 쿠폰과 할인 조건을 확인하고 쿠폰 코드를 복사하거나 페이지를 공유할 수 있습니다.
- 관리자 쿠폰 목록에서 현장 확인 후 `사용 처리`를 눌러 사용 횟수를 기록합니다.
- 사용 처리는 서버에서 활성 상태, 유효기간, 발급 한도를 다시 확인하는 조건부 UPDATE로 수행합니다. 동시 요청으로 최대 수량을 초과하지 않도록 DB 조건을 한 번에 적용합니다.

## API
- `PATCH /api/coupons/:id?shop_key=...` + `{ "action": "redeem" }`
- 관리자 인증 및 프로모션 요금제 권한을 확인합니다.
- 쿠폰이 비활성/기간 만료/수량 소진 상태면 `409 coupon_unavailable`을 반환합니다.

## 제한 및 운영 유의사항
- 쿠폰 페이지는 공개 링크이며, 코드를 복사한 것만으로 사용 처리되지 않습니다.
- 사용 처리는 직원이 고객의 현장 제시를 확인한 뒤 관리자 화면에서 직접 수행합니다.
- POS/결제 시스템과 자동 할인 연동은 포함하지 않습니다.
- 실제 배포 후 D1 동시 요청, 관리자 인증, 모바일 공유 API 동작을 검증해야 합니다.
