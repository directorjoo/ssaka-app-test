# 싸카 v8 — 본사 운영센터

## 추가된 기능
- `/hq-admin/` 본사 운영자 화면
- 매장명·전화번호·매장 키 검색
- 운영 중/중지 필터
- 전체 매장, 운영 매장, 누적 예약, 대기 예약 요약
- 매장별 예약 건수 및 상태별 카운트
- 매장 운영 중지/재개 (예약 데이터는 삭제하지 않음)
- 본사 전용 API `GET/PATCH /api/hq/shops`

## Cloudflare Pages 설정
1. Pages 프로젝트의 D1 binding 이름이 `DB`인지 확인합니다.
2. Settings → Environment variables 에서 `HQ_ADMIN_KEY`를 Secret으로 등록합니다.
3. 최소 24자 이상의 무작위 값을 사용합니다. 예: `openssl rand -hex 32`로 생성한 값.
4. 배포 후 `/hq-admin/`에 접속해 본사 운영 키로 인증합니다.

## 보안/운영 주의
- 본사 키는 프런트엔드 코드나 저장소에 넣지 않습니다. 서버 Secret으로만 설정합니다.
- 본사 화면은 단일 공유 키 방식입니다. 상용 출시 전 개인별 운영자 계정, MFA, 접근 로그, IP/요청 제한을 추가해야 합니다.
- 현재 입점 등록 API는 공개 POST 방식입니다. 실제 영업 전에는 신청/승인 상태와 사업자 확인 절차를 추가해야 합니다.
- 매장 중지는 매장별 관리자 API 사용을 막습니다. 예약 이력은 보존합니다.
- 매출/구독 금액은 실제 결제 데이터가 없어 산출하지 않습니다. v8의 통계는 매장 수와 예약 건수만 표시합니다.
- 이 소스는 배포 준비물이며 Cloudflare 계정에 실제 배포하거나 실서비스 D1에서 검증한 것은 아닙니다.
