# 싸카 v7 — 요금제/수익화 기반

## 요금제 제안 (출시 전 검증 필요)

| 요금제 | 월 제안가 | 핵심 제공 | 목적 |
|---|---:|---|---|
| 스타터 | 무료 | 기본 소개 페이지, 연락/길찾기, 예약관리(월 30건 제안) | 입점 장벽 최소화 |
| 플러스 | 29,000원 | 예약 무제한, 프리미엄 디자인, 월간 통계 | 주력 반복 매출 |
| 프로 | 59,000원 | 플러스 + 프로모션 크레딧, 재방문 분석, 직원 계정 | 성장 매장 업셀 |

가격·제한 수치는 실제 고객 인터뷰와 원가/전환율 검증 전의 가설이다. API는 요금제 카탈로그만 제공하며 결제나 구독 상태를 변경하지 않는다.

## 현재 구현
- `GET /api/plans`: 공개 요금제 카탈로그(JSON)
- 파트너 관리자 페이지에서 요금제 제안안을 확인
- 결제 미연동 상태를 명시해 유료 기능이 활성화된 것처럼 오인하지 않도록 처리

## 결제 도입 전 필수 작업
1. 사업자/매장 검증 및 이용약관·환불정책 확정
2. PG사 계약 및 결제창/빌링키 흐름 구현
3. PG 웹훅 서명 검증, 중복 이벤트 방지, 결제 실패/해지 처리
4. D1 구독 테이블에 상태·기간·PG 거래 ID 저장
5. 서버에서 매 요청마다 요금제 권한 검증 (화면 숨김만으로 제한하지 않음)
6. 세금계산서/현금영수증, 개인정보 처리·보관 정책 점검

## 출시 전략
- 초기 10~20개 매장은 스타터로 온보딩하고 예약 흐름/반복 사용을 검증
- 플러스는 예약량과 관리시간 절감이 확인된 뒤 유료 전환 테스트
- 프로 광고상품은 실제 노출·클릭·예약 전환 데이터를 확보한 뒤 판매
- 광고비는 예약 성과와 분리해 명확히 표시하고, 광고 미구매 매장도 기본 검색 노출 기회를 보장
