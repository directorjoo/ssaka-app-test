# 싸카 v11 — 식당·카페 메뉴판 자동 정리

## 목표
사장님이 기존 예약 메뉴 입력란에 메뉴명과 가격을 줄 단위로 입력하면 고객용 카드에서 소개 문장과 구분된 메뉴판으로 정돈해 보여준다.

## 동작
1. `/make/`에서 매장(식당·카페) 카드를 만든다.
2. 예약 받기를 켜고 메뉴 입력란에 `메뉴명 가격` 형식으로 입력한다.
3. 기존 `SsakaReserve.parseMenu()`가 `{ n, p }` 데이터로 변환한다.
4. `SsakaRender.build()`가 메뉴 항목을 전용 `sk-menu` 영역으로 렌더링한다.
5. 가격은 1,000 단위 구분기호와 `원`을 붙이고, 가격이 없는 항목은 이름만 표시한다.

## 구현 파일
- `js/render.js`: 메뉴판 마크업 및 안전한 DOM 텍스트 렌더링
- `css/sk-world.css`: 메뉴판 레이아웃과 테마 공통 스타일
- `README.md`: v11 변경사항

## 호환성 및 제한
- 예약 데이터의 기존 `reserve.menu` 구조 `{ n, p }`를 재사용하므로 데이터 형식을 변경하지 않는다.
- 현재 메뉴판은 예약 기능을 켰을 때 저장된 메뉴 데이터를 기준으로 표시한다.
- 메뉴 사진별 연결, 카테고리 분류, 품절 표시, 메뉴별 상세 설명은 다음 단계 기능이다.
- 브라우저 실사용, 실제 예약 접수, Cloudflare 운영 배포 검증은 별도 수행해야 한다.
