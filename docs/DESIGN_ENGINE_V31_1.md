# SSAKA Design Engine v31.1

## 목적
기존 단일 배경+텍스트 오버레이 방식을 폐기하고, 서로 다른 정보 위계와 이미지 배치를 갖는 6개 아트디렉션을 제공한다.

## 6개 구성 엔진
- 사진 중심형: 대형 히어로 이미지, 제목/설명 분리, 매장 정보 하단 고정
- 매거진형: 편집 디자인 타이포그래피, 비대칭 이미지 프레임, 넘버링
- 프리미엄: 다크 톤, 세리프 타이포그래피, 얇은 프레임과 절제된 포인트 컬러
- 프로모션형: 혜택/가격의 우선 노출, 강한 컬러 밴드, 사진과 설명 분리
- 따뜻한 감성: 라운드 이미지, 부드러운 색면, 감성형 제목 위계
- 미니멀: 불필요한 장식 제거, 사진과 핵심 메시지 중심

## 공통 품질 규칙
- 모든 채널 규격별 캔버스에 맞춰 레이아웃을 다시 계산한다.
- 한국어 글자는 공백 단위가 아니라 문자 폭 기준으로 줄바꿈한다.
- 사진은 박스별 cover crop으로 배치하며 배경 전체에 흐리게 덮는 기존 방식을 제거한다.
- 가격/혜택이 없으면 해당 요소를 렌더링하지 않는다.
- 매장명과 지역 정보는 하단 정보 영역으로 분리한다.

## 다음 고도화 우선순위
1. 사진 초점 위치 조절(인물/음식 피사체 보호)
2. 메뉴/업종별 레이아웃 추천
3. 브랜드 컬러 추출 및 폰트 페어링
4. 실제 출력 이미지에 대한 자동 가독성/겹침 검사
5. 채널별 안전영역 프리셋
