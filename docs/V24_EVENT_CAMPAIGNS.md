# 싸카 v24 이벤트 캠페인 연결

## 고객 공유
관리자 이벤트 목록의 `이 이벤트 전용 링크`를 공유하면 해당 이벤트만 노출됩니다. 기존 매장 전체 이벤트 링크는 그대로 유지됩니다.

## 이벤트 쿠폰
쿠폰 발행 폼에서 연결 이벤트를 선택할 수 있습니다. 선택하지 않으면 전체 매장 쿠폰으로 저장됩니다. API는 선택된 이벤트가 같은 매장 소유인지 확인한 뒤 `source_event_id`를 저장합니다.

## 데이터 변경
`shop_coupons.source_event_id TEXT` 컬럼을 추가합니다. 쿠폰 API의 ensure 단계에서 기존 테이블의 컬럼 목록을 확인한 후 없는 경우에만 ALTER TABLE을 실행합니다.

## 검증 범위
정적 JavaScript 문법 검사와 ZIP 무결성 검사만 수행합니다. D1 운영 DB 마이그레이션, Cloudflare 배포, 실제 모바일 브라우저 테스트는 별도 수행해야 합니다.
