# 싸카 v10 디자인 추천 기능

## 목표
템플릿 수를 단순히 늘리는 대신, 업종에 맞는 디자인을 빠르게 선택하고 정보가 산만해지지 않도록 돕는다.

## 사용자 기능
- `/make/`의 디자인 선택 영역에 `깔끔한 디자인 자동 추천` 버튼 제공
- 현재 선택된 업종의 디자인 목록을 기준으로 추천
- 우선순위: `magazine` → `safe` → `glass`
- 세 계열이 해당 업종에 없으면 해당 업종의 첫 번째 디자인을 사용
- 추천 이유를 짧게 안내하고 선택된 템플릿으로 스크롤

## 동작과 한계
- 기존 `SsakaDesigns.list(industry)`와 `setDesign()`을 사용하므로 카드 인코딩, 미리보기, 공유 방식은 변경하지 않는다.
- 이는 규칙 기반 추천이며 생성형 AI가 아니다.
- 향후 AI 이미지 정리, 메뉴판 자동 배치, 문구 생성은 별도 서버/API와 비용·저작권·개인정보 검토 후 추가한다.

## 검증
- 브라우저에서 업종별 추천 버튼, 디자인 선택 표시, 미리보기 갱신, 카드 저장 및 공유를 확인한다.
- 실제 배포 환경 검증은 운영 도메인에서 별도로 수행한다.
