# 싸카 v13 식당 전환형 메뉴 및 행동 영역

## 추가 사항
- 메뉴 입력 형식에 설명과 대표 표시 필드를 추가했습니다.
- `대표` 카테고리 또는 마지막 필드 `대표`로 대표 메뉴 배지를 표시합니다.
- `인기` 카테고리는 인기 메뉴 배지로 표시합니다.
- 메뉴 설명은 메뉴명 아래 보조 문구로 표시합니다.
- 예약 메뉴가 있는 카드의 바로가기 영역에 하단 sticky dock 스타일을 적용했습니다. 전화·예약·길찾기 등 기존 액션 핸들러는 변경하지 않았습니다.

## 입력 예시
`삼겹살 15000 | 대표 | https://example.com/pork.jpg | | 국내산 생삼겹살 180g | 대표`

`된장찌개 8000 | 식사 | | | 매장에서 직접 끓인 구수한 된장찌개`

`콜라 2000 | 인기`

## 호환성 및 주의
- 기존 1~4열 입력 형식은 그대로 동작하도록 확장 필드만 추가했습니다.
- `대표`와 `인기`는 기존 카테고리 필드를 활용합니다.
- 하단 액션 영역은 CSS sticky 방식이며, 임베드/외부 브라우저의 스크롤 구조에 따라 고정 위치 체감은 달라질 수 있습니다.
- 본 버전은 정적 문법 및 패키지 검증 기준이며, 실제 결제·예약 운영 및 다양한 모바일 브라우저 검증은 배포 전 별도 수행해야 합니다.
