# 싸카 v18 매장 성과 분석 연결

## 수집 항목
- `view`: 매장 페이지 조회 (동일 익명 브라우저는 24시간 내 중복 제거)
- `call`, `reserve`, `directions`, `share`, `menu`: 고객 행동 이벤트

## 익명 방문자 집계
브라우저는 로컬 저장소에 임의 UUID를 생성해 페이지 조회 시에만 전송합니다. 이 값은 계정·이름·전화번호와 연결하지 않습니다. 30일 고유 방문 브라우저 수는 기기/브라우저 단위의 추정치이며, 다른 기기·브라우저 또는 저장소 초기화는 별도 방문자로 집계될 수 있습니다.

## 배포 확인
1. Cloudflare D1에 `shop_analytics_events` 테이블이 생성되는지 확인합니다. 기존 테이블에는 `visitor_id` 컬럼을 자동 추가합니다.
2. 매장 전용 고객 링크를 열어 페이지 조회 이벤트가 쌓이는지 확인합니다.
3. 전화·예약·길찾기·공유·메뉴 클릭 이벤트를 각각 확인합니다.
4. 플러스/프로 매장 관리자에서 통계가 표시되는지 확인합니다.
5. 실제 고객 공지/개인정보 처리방침에 익명 분석 데이터 수집 사실을 반영합니다.

## 한계
고유 방문자 수는 익명 브라우저 식별자 기반 추정치이며 실제 사람 수가 아닙니다. 이벤트 수집은 브라우저 저장소 제한, 광고 차단, 네트워크 오류에 영향을 받을 수 있습니다. 매장 단위 분당 600건 제한은 기본적인 과다 호출 방지이며 정교한 봇 방어·IP 기반 제한을 대체하지 않습니다.
