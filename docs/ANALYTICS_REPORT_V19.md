# 싸카 v19 — 매장 성과 리포트

## 추가 기능
- 최근 30일 시간대별 페이지 조회(한국 표준시 UTC+9)
- 최근 30일 요일별 페이지 조회
- 메뉴 클릭 이벤트의 메뉴명별 TOP 5
- 페이지 조회 대비 전화·예약·길찾기 클릭 비율(클릭 이벤트 수 / 조회 이벤트 수)
- 관리자 대시보드에 위 리포트 표시

## 데이터 해석 및 제한
- 시간대·요일은 서버에서 기록한 이벤트 시각을 한국 표준시로 변환해 집계합니다.
- 전환율은 고유 사용자 단위의 전환율이 아니라 클릭 이벤트 수를 페이지 조회 수로 나눈 참고 지표입니다. 한 사용자의 반복 클릭이 포함될 수 있습니다.
- 메뉴 TOP 5는 클릭된 메뉴 요소에서 메뉴명을 읽을 수 있는 경우에만 집계됩니다. 기존 페이지 요소에 메뉴명이 연결되지 않으면 해당 클릭은 기존 전체 메뉴 클릭 수에만 포함됩니다.
- 데이터가 없는 구간은 0 또는 안내 문구로 표시됩니다.
- 관리자 GET 요청은 기존과 동일하게 관리자 키 및 플러스 이상 통계 권한이 필요합니다.

## 운영 전 확인
- Cloudflare Pages Functions와 D1에서 SQLite `strftime` 및 `json_extract` 쿼리를 확인합니다.
- 실제 고객 페이지에서 메뉴 클릭 요소의 이름이 수집되는지 검증합니다.
- 본 지표는 매출/결제 데이터가 아니며 실제 매출이나 예약 확정 건수를 의미하지 않습니다.
