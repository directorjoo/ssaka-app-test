# 싸카 v12 — 식당 메뉴판 고도화

## 입력 규칙
기존 입력 방식은 그대로 지원합니다.

`김치찌개 9000`

확장 입력은 파이프(|)로 구분합니다.

`김치찌개 9000 | 식사 | https://example.com/kimchi.jpg | 품절`

필드 순서: 메뉴명+가격 / 카테고리 / 사진 URL / 품절 상태. 카테고리·사진·품절은 선택 항목이며 빈 칸도 허용합니다.

## 표시 기능
- 카테고리가 바뀌면 메뉴판에 카테고리 제목을 표시합니다.
- 사진 URL이 있으면 메뉴 왼쪽에 썸네일을 표시합니다.
- 마지막 필드가 `품절` 또는 `sold out`이면 품절 상태를 표시합니다.
- 품절 메뉴도 가격과 함께 노출하되 이름에 취소선을 적용합니다.

## 호환성과 검증 범위
- 메뉴의 예약 데이터 핵심 필드 `n`, `p`를 유지하고 화면 전용 메타데이터 `category`, `image`, `soldout`를 추가합니다.
- 기존의 단순 메뉴 입력 방식은 변경 없이 작동하도록 구성했습니다.
- 배포 전 실제 브라우저, 이미지 호스팅 CORS/접근성, 예약 접수 흐름 검증이 필요합니다.
