# 싸카 v16 — 매장 관리 기능

## 추가 기능
- `/admin/` 매장 관리자 화면에서 매장명, 전화번호, 주소, 소개, 대표 사진 HTTPS URL 수정
- 메뉴 CRUD API: `GET/POST /api/menu?shop_key=...`, `PATCH/DELETE /api/menu/:id?shop_key=...`
- 메뉴별 가격, 카테고리, 설명, HTTPS 사진 URL, 품절 상태, 정렬 순서 저장
- 기존 예약 상태 관리와 통계 화면 유지

## 데이터베이스
D1 `DB` 바인딩 필요. `restaurant_menu_items` 테이블 및 인덱스는 API 호출 시 생성됩니다. 매장 프로필에 `address`, `description`, `image_url` 컬럼이 없으면 API가 추가합니다.

## 보안 및 제한
- 메뉴 API는 매장별 관리자 키(`x-ssaka-admin`)를 SHA-256 해시와 비교해 인증합니다.
- 메뉴 조회도 관리자 인증을 요구합니다. 공개 매장 페이지에서 메뉴를 보여주려면 별도의 공개 읽기 전용 API 및 렌더러 연결이 필요합니다.
- 사진 URL은 HTTPS만 허용합니다. 이미지 파일 업로드/저장 기능은 포함하지 않습니다.
- 매장 소개 및 메뉴 변경 사항은 DB에 저장되지만, 공개 페이지 렌더러에 자동 반영되도록 연결하는 작업은 후속 단계입니다.
- Toss 결제/구독 자동 활성화 및 실결제 테스트는 이 버전의 범위가 아닙니다.

## 배포 전 확인
1. Cloudflare Pages Functions에 D1 `DB` 바인딩 설정
2. `/admin/`에서 매장 관리자 인증 후 프로필 저장 확인
3. 메뉴 추가·수정·품절·삭제 API 테스트
4. 공개 페이지 렌더러와 메뉴 공개 API 연동
