# SSAKA Restaurant 48 Design Gallery — v32.1

## 목적
식당 입력 정보와 대표 사진을 유지하면서 8개 레이아웃과 6개 아트디렉션 조합을 실제 캔버스 렌더링으로 비교합니다.

## 48개 구성
- 레이아웃 8종: 풀블리드 히어로, 비대칭 스플릿, 에디토리얼 그리드, 타이포그래피 포스터, 프레임 갤러리, 오퍼 포커스, 스토리 콜라주, 카탈로그 카드
- 아트디렉션 6종: 포토 에디토리얼, 매거진, 럭셔리, 세일즈, 웜 라이프, 미니멀
- 총 48개 조합

## 사용
1. `studio/index.html` 실행
2. 기본 입력된 싸바식당 샘플을 확인하고 대표 사진을 업로드
3. `48개 디자인 전체 비교하기` 선택
4. 48개 미리보기 중 하나를 선택하거나 전체 이미지를 저장

## 주의
- 전체 48개는 동일한 현재 입력을 사용하며 각 조합별로 캔버스에서 렌더링됩니다.
- 이번 버전은 기존 8개 레이아웃 렌더러와 6개 색상/타이포그래피 아트디렉션을 조합한 갤러리 기능입니다. 48개의 독립적인 전문 아트디렉션이 별도로 설계·시각 검수된 상태를 의미하지 않습니다.
- 실제 브라우저 스크린샷 및 기기별 시각 QA는 별도 수행이 필요합니다.
- 운영 배포 설정, API, 인증, 데이터베이스, 기존 앱 기능은 변경하지 않았습니다.
