# 다중 디자인 플랫폼 연결 정책

## 통합 원칙
싸바 자체 디자인 엔진을 중심에 두고 외부 앱은 연결 가능한 범위에서 provider adapter로 연결한다.
업체 정보(상호, 메뉴, 가격, 브랜드 색, 이미지)를 공통 `DesignJob`으로 정규화하고,
각 공급자별로 지원하는 작업만 전달한다.

## 현재 판단
| 서비스 | 연결 방식 | 현 단계 |
|---|---|---|
| Canva | OAuth + Connect REST API | 개발자 앱/스코프 설정 후 API 연동 가능 |
| Adobe Express | Embed SDK + Express API | Adobe 프로젝트/권한 설정 후 에디터 임베드 |
| Figma | OAuth + REST API | 파일/에셋 작업 가능 범위 확인, 완전한 편집기 대체는 아님 |
| 미리캔버스 | 공식 파트너/API 협의 또는 AI 커넥터 사용 흐름 | 범용 외부 SaaS API 접근권 미확인 |
| 망고보드 | 공식 파트너/API 협의 | 범용 외부 SaaS API 접근권 미확인 |

## 다음 개발 순서
1. Canva OAuth/디자인 생성·내보내기·Autofill 실제 권한 테스트
2. Adobe Express Embed SDK를 싸바 제작 화면에 삽입
3. Figma OAuth callback, 토큰 저장소, 파일/이미지 export 연동
4. 미리캔버스 및 망고보드에 제휴/API 제공 여부와 상업적 사용 범위 문의
5. 공통 DesignJob 큐, 파일 저장소, 사용량·비용 기록, 실패 재시도 구현

## 라이선스
외부 서비스의 디자인 템플릿, 사진, 폰트, 스톡 에셋은 각 라이선스가 허용하는 범위에서만 사용한다.
외부 플랫폼에서 편집한 디자인을 싸바 디자이너 마켓에서 재판매하는 행위는 별도 권리 확인 없이는 허용하지 않는다.
