# 싸카 v20 — 쿠폰·이벤트 홍보

## 구현 범위
- `GET/POST /api/coupons?shop_key=...`: 관리자 인증 후 쿠폰 조회·발행
- `PATCH/DELETE /api/coupons/:id?shop_key=...`: 쿠폰 활성/중지 및 삭제
- 모든 관리 API는 `x-ssaka-admin` 키를 검증하고 서버의 현재 이용권 권한을 확인합니다.
- 쿠폰 발행은 `promotion` 권한이 있는 프로 요금제에서만 허용합니다.
- `GET /api/public/shops/:shop_key` 응답에 현재 유효한 공개 쿠폰을 최대 10개 포함합니다.
- 고객용 매장 카드 페이지는 공개 쿠폰을 표시하고 쿠폰 코드를 복사할 수 있습니다.

## 쿠폰 규칙
- 할인 방식: 정률(1~100%) 또는 정액(1~1,000,000원)
- 최소 주문 금액 및 발급 가능 수량(0은 무제한)을 설정할 수 있습니다.
- 시작·종료 시각은 한국 날짜 입력을 기준으로 Unix milliseconds로 저장합니다.
- 코드 중복은 매장 단위로 제한합니다.
- 비활성, 기간 외, 발급 수량 소진 쿠폰은 공개 API에서 제외합니다.

## 중요한 운영 한계
- 현재 기능은 쿠폰 발행·공개·코드 복사까지입니다.
- POS/결제 시스템과 연동한 자동 할인 적용, 실제 사용 검증, 사용 횟수 차감은 아직 구현하지 않았습니다. 매장 직원이 현장에서 조건을 확인해야 합니다.
- 관리자 인증은 기존 `x-ssaka-admin` 키 방식입니다. 운영 전 HTTPS, 키 보관·회전 정책, D1 백업 및 Cloudflare 로그 점검이 필요합니다.
- 실제 D1 운영 DB와 결제 환경에서의 통합 테스트는 배포 후 별도 수행해야 합니다.
