# 사업계획서 — 싸카 (SSAKA / 싸바카드)

인터랙티브 웹 기반 모바일 카드 & 바이럴 커뮤니케이션 플랫폼

## 1. 사업 요약

- 서비스명: 싸카 (SSAKA / 싸바카드)
- 미션: 앱 설치 없이 카카오톡 공유 한 번으로 통화 · 위치 · 주소록 저장 · 바이럴 게임까지 끝나는 모바일 웹 카드
- 차별점
  1. Zero Barrier — 웹(HTML/JS) 기반. 카톡 링크 터치 한 번으로 실행, 보내는 것도 카톡 무료 공유
  2. 4대 핵심 버튼 — 원터치 통화(tel:), 길찾기 앱 호출, 주소록(.vcf) 저장, 계좌/링크 복사
  3. 바이럴 엔진 — 숨은 짤 찾기, 럭키 복권/퀴즈 카드로 단톡방 자발적 확산 → 유저 획득비용(CAC) 최소화

## 2. 문제와 해결

| 문제 | 싸카의 해결 |
|---|---|
| 받는 사람이 앱을 깔아야 볼 수 있어 대부분 이탈 | 100% 모바일 웹. 카톡 미리보기 클릭 → 브라우저에서 바로 열림 |
| 이미지·텍스트뿐인 정적인 카드, 클릭할 이유가 없음 | 통화/위치/주소록/복사 버튼 + 게임 요소로 참여 유도 |
| PDF·이미지 프로필은 영상 재생, 번호 보호가 안 됨 | 유튜브/인스타 영상 원터치 재생, 번호 보호 수신 처리, 원터치 주소록 저장 |

## 3. 템플릿 라인업

### 1단계 — 착한 나눔 (무료, 유저 확보)
- 신인 배우/영화인 프로필 카드: 프로필 사진 + 필모그래피 + 연기 영상 + 캐스팅 통화 버튼, 번호 보호 처리
- 어린이 안심 카드 ("엄마! 나 지금 여기야!"): 원터치 위치 보내기(GPS) + 긴급 통화
- 어르신 안심 카드: 고대비 초대형 SOS 버튼, 비상 연락처 통화, 보호자에게 위치 전송

### 2단계 — 모임 & 비즈니스 (실사용 + 소상공인 결제)
- 산악회/동문회 공지 카드: 장소 지도(카카오맵/네이버지도) + 총무 통화 + 회비 계좌 복사
- 소상공인 10초 홍보 카드: 오늘의 메뉴/영업시간 + 예약 통화 + 길찾기

### 3단계 — 바이럴 펀 게임 (단톡방 유입 엔진)
- 숨은 짤 찾기 / 럭키 복권 / 퀴즈 카드 ("이 단톡방에서 보물 찾기 1초 컷?")
- 당첨/꽝 로직 + 효과음으로 공유 욕구 자극

## 5. 수익 구조와 성장 경로

1. 무료 템플릿(배우/안심/모임)으로 트래픽 확보 — 광고비 없이
2. 바이럴 게임 카드로 단톡방 확산 — DAU/MAU 증대
3. 수익화 (B2B SaaS)
   - 비즈니스 프리미엄 월 구독 (소상공인·프리랜서·영업직: 고급 디자인, 열람 통계, 예약 장부·자동 확정)
   - 커머스 수수료 (화환 주문, 기프티콘/답례품 선물하기)
   - 유료 디자인 템플릿 마켓 — 캔바·망고보드 등에서 활동하는 디자이너가 만든 템플릿 판매, 디자이너 7 : 싸카 3 (2026-11-07 결정)
     - 초기에는 업종별 자동 생성 템플릿(무료 192종)으로 시작하고, 사용자가 쌓이면 마켓 오픈
   - (보류) 대량 알림톡/문자 발송 마진 — 아래 "발송 방침" 참고
4. 대형 IT/플랫폼 기업 대상 M&A (Exit)

## 6. 발송 방침 (2026-11-07 결정)

- 문자·알림톡 대량 발송 마진은 일단 포기하고, 카카오톡 무료 공유로 시작한다.
- 방법: 카드마다 "카톡으로 보내기" 버튼. 사용자가 직접 친구·단톡방을 골라 보낸다.
  - 1순위: 카카오 JavaScript SDK 공유 — 무료, 카카오 로그인 불필요. 카카오디벨로퍼스 앱 등록 + 도메인 등록 + JavaScript 키 필요
  - 키 등록 전: 휴대폰 기본 공유창(목록에서 카카오톡 선택) → 그것도 안 되면 링크 복사
- 장점: 발송 비용 0원, 대행사 계약·템플릿 심사 없음, 바로 시작 가능
- 한계: 한 번에 여러 명에게 자동 발송은 안 됨(사람이 직접 고름). 대량 자동 발송이 필요한 고객이 쌓이면 그때 알림톡을 유료 옵션으로 다시 검토

## 7. 어디야? — 독립 서비스 후보 (2026-11-07)

- 한국인이 전화·카톡·문자에서 가장 먼저 하는 말이 "어디야?" — 안부 인사보다 자주 쓰는, 설명이 필요 없는 기능
- 아주 단순하게: "여기로 와!"(약속 장소·시간·지도·길찾기) / "어디야?"(버튼 하나로 내 위치 답장)
- 싸카의 유입 입구 역할: 매일 쓰는 가벼운 기능으로 사용자를 모으고, 받은 사람이 "나도 보내기"로 다시 보내는 구조
- 이후 실시간 위치 공유, 모임 출석 체크, 가게 "오시는 길" 카드와 연결

## 8. 검토가 필요한 점 (정리하면서 짚어 둔 것)

- 번호 보호 수신 처리: 웹만으로는 번호를 숨긴 채 전화를 연결할 수 없습니다. 050 안심번호(가상번호) 서비스 연동이 필요하고, 건당 비용이 발생하므로 무료 배우 카드에 넣을지, 유료 옵션으로 둘지 결정 필요.
- 어린이/어르신 위치 전송: 위치는 받는 사람이 아니라 카드를 연 사람(아이·어르신) 휴대폰에서 브라우저 위치 권한을 허용해야 얻을 수 있습니다. 프로토타입은 "내 위치를 문자/카톡으로 보내기" 방식으로 구현. 자동 추적은 위치정보법상 사업자 신고 대상이므로 범위 밖으로 둠.
- 대량 알림톡: 보류. 재검토 시 카카오 비즈메시지 공식 딜러(대행사) 계약과 템플릿 사전 심사가 필요함.
- 복권/당첨 게임: 경품이 실제 금전·물품이면 사행성·경품 관련 규정 검토 필요. 초기에는 경품 없는 재미용으로 시작하는 것을 권장.
