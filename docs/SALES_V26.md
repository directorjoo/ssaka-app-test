# 싸카 v26 매출 기록·캠페인 기여 분석

## 동작
- `POST /api/sales?shop_key=...`: 매장 관리자가 확인한 매출을 입력합니다.
- `GET /api/sales?shop_key=...`: 최근 30일 총매출, 주문 수, 입력 건수와 이벤트/쿠폰별 매출을 반환합니다.
- 매출은 `shop_sales`에 저장되며 `source_event_id`, `coupon_code`는 선택 입력입니다.
- 이벤트 ID는 같은 매장 소유 이벤트인지 검증하고, 쿠폰 코드는 같은 매장에 등록된 코드인지 검증합니다.

## 주의
이 기능은 POS/PG 결제 데이터를 자동 수집하지 않습니다. 현장 매출을 관리자가 직접 기록해야 하며, 쿠폰 할인액과 실제 결제액을 구분하려면 후속 POS 연동 또는 별도 할인액 필드가 필요합니다. D1 운영 환경에서 API/권한/마이그레이션 테스트 후 배포하세요.
